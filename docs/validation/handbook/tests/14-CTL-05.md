## What to check at Level 0

| Line or block | Expect |
|---|---|
| Files | One file, `acceptance-carbide-motion.nc` |
| Start | `G90 G94 G17`, `G20` |
| Each tool change | `M5`, a comment, `T1 M6` or `T2 M6`, `G90 G94`, `M8`, `S… M3` |
| Dwell | `G4 P3.00` |
| Long comment | Shortened to fit (the third toolpath's name) |
| End | `M5`, `M9`, `M30` |

## Steps

1. Load it in Carbide Motion: no errors, and the preview inside the scrap.
2. The common procedure's Levels 1 and 3: Carbide Motion should stop at each `M6`, ask for the bit and (with a BitSetter or BitZero) measure it.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Carbide Motion stops at both `M6` changes | Yes | | |

## Failure and what to report

The Carbide Motion version, the machine, how you zero tools, the error and line, and the measurements.
