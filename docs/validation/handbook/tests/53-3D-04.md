## Setup

All three patterns finish the same coin, so cut them on **three blanks**: in the app, turn on one toolpath at a time and export each, or cut all three on one blank to compare the moves only. The coin is 3.2 mm deep inside a 30 mm circle.

## Steps

1. Level 0 and Level 1: the spiral must run as one continuous move without stopping; the radial spokes link without lifting where they can.
2. Level 3, one pattern per blank. Compare the surfaces under raking light.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Coin's depth | 3.2 mm | ±0.13 mm | | |
| Constant scallop: even scallops over flats and slopes | Yes | — | | |
| Spiral: no stops or dwell marks along the spiral | Yes | — | | |
| Radial: spokes evenly spaced, no gouge at the centre | Yes | — | | |
| All three match the model's shape | Yes | — | | |

## Failure and what to report

Marks where the spiral stops, scallops visibly uneven, or the centre of the radial pattern dug in. Photos.
