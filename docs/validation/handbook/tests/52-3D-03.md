## Setup

A medallion model as deep as the board, inside a 96 mm circle, cut out on 3 tabs 3/8 × 1/8 in. `post` says where each strip is: 0.375 in long, its top 0.625 in deep, 0.125 in above the material's bottom.

The chip-load warnings are expected: this fixture keeps the starter feeds in MDF. Raise the feeds as each warning suggests if your machine can, or leave them.

## Steps

1. Level 0: read the three `Leaves a strip under each of the 3 tabs` lines.
2. Level 1 with Z zeroed well above the stock: check the roughing and the finish never go below Z −0.625 in **at the tabs**, and the cut-out's tabs come in at Z −0.625 in.
3. Level 3. After the roughing and again after the finish, check the part is still firmly held. Then caliper the tabs after the cut-out. Time the clean-up.
4. Re-zero Z with the touch plate at the change to the ball nose: note how much the tab thickness moves if you re-zero a second time.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Part held after the roughing, and after the finish | Yes | — | | |
| Three tabs, each about 0.375 in long | 0.125 in (3.2 mm) thick | ±0.010 in | | |
| Ball's fillet at each strip's foot (describe) | Small witness only | — | | |
| Clean-up time per part (note it) | — | — | | |

If you have hardwood, repeat in it with the tabs across the grain and note any tab that cracks during finishing.

## Failure and what to report

A part that comes free before the cut-out finishes is a safety finding: stop, photograph it, and report it with the file. Tab thicknesses, and whether 3/16 in tabs would have suited better.
