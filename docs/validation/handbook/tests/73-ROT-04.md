## Setup

For another controller, open the project in the app, choose your machine (keep **Turn by hand** on under Rotary Axis), and save a copy. Set your indexer's centre height. Zero on the axis as in VH-ROT-03.

## Steps

1. Level 0: before every new angle the file has a retract to safe Z, `M5` (spindle off), a comment such as `(Turn the blank to 90deg, then Cycle Start)`, `M0`, then the spindle restart. The first toolpath of each file asks for its angle too.
2. Level 1: at each stop, check the spindle has stopped and the tool is clear, turn the blank to the angle named, and resume.
3. Level 3.

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Every stop: spindle off, tool at safe Z, the angle named | Yes | | |
| Spindle back up to speed (dwell) before the next cut | Yes | | |
| Mortise, holes and V-carved panel on each of the four faces | Yes | | |
| Features the same distance from the chuck end on every face | ±0.010 in | | |
| Time per hand turn (note it; NativeCAM assumes 30 s) | — | | |

## Failure and what to report

A stop with the spindle still running or the tool low is a safety finding: report it at once. The controller, the sender, and how its pause behaved.
