## Steps

1. Level 0. Look for the F changes inside each toolpath (lower F words at corners and full-width cuts).
2. Level 1: watch for stops or hesitations at each F change. Time the job against the estimate.
3. Level 3. Check the walls for marks where the feed changes.
4. Optional: in the app, set **Spindle ▸ Automatic** on the cut-out and post again. The 1/4 in end mill at 400 in/min should get about 22,900 RPM. Cut a short test in scrap hardwood and check the chip and edge.

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| No stops or marks at F changes | Yes | | |
| Air-cut time against the estimate | ±15% | | |
| Recess 3 × 2 in and well 1.5 × 1.5 in to size | ±0.005 in | | |
| Automatic spindle speed chosen (note it) | about 22,900 RPM at 400 in/min | | |

## Failure and what to report

Visible marks or stalls at F changes: note your controller's constant-velocity settings. That result decides whether this option can default on.
