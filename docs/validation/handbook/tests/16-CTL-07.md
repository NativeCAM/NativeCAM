## What to check at Level 0

| Line or block | Expect |
|---|---|
| Start | `G90 G94 G17`, `G20`; no `G43`, `G64` or `G91.1` |
| Each tool change | `M5`, `T1 M6` (Masso applies the length itself), `G90 G94`, `M8`, `S… M3` |
| Dwell | `G4 P3000`: **milliseconds** |
| End | `M5`, `M9`, `M30` |

## Steps

1. Load it on the Masso: no errors.
2. The common procedure's Levels 1 and 3. **Time the dwell**: 3 s. A dwell of 3000 s (50 minutes) or 3 ms means the unit is wrong: stop and report it.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Dwell at the helix's foot | 3.0 s | | |
| Masso stops at both tool changes | Yes | | |

## Failure and what to report

The Masso model and firmware, the dwell you timed, the error and line, and the measurements.
