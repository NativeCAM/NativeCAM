## What to check at Level 0

| Line or block | Expect |
|---|---|
| Files | Three `.sbp` files, one per tool |
| Start | `IF %(25)=1 THEN GOTO UNIT_ERROR` (in an inch file: refuses to run with ShopBot set to mm), `SA`, `JS,…` |
| Spindle | `TR,18000` then `C6` (spindle on); `C7` at the end |
| Speeds | `MS,` in units per **second** (for example `MS,0.656,0.197` for 39.4 and 11.8 in/min) |
| Dwell | `PAUSE 3.00` in file 2 |
| End | `J2,0.0000,0.0000`, `C7`, `END`, then the `UNIT_ERROR:` block |

## Steps

1. Open each file in the ShopBot control software's preview: no errors. Switch the software to millimetres and load file 1: it must stop with the unit message. Switch back.
2. The common procedure's Levels 1 and 3, the files in order, zeroing Z (C2) between them.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Inch file refuses to run in mm mode | Yes | | |
| `PAUSE 3.00` waits 3 s | 3.0 s | | |
| Spindle starts on `C6` (or is started by hand) | Yes | | |

## Failure and what to report

The ShopBot control software's version, the machine, the message shown and line, and the measurements.
