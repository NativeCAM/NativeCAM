## What to check at Level 0

| Line or block | Expect |
|---|---|
| Start | `G90 G94 G17`, `G20` |
| Each tool change | `M5`, `T1 M6` then `G43 H1` (from CNC12's tool library; a tool with no length gets 0), `G90 G94`, `M7`, `S… M3` |
| Dwell | `G4 P3.00` |
| End | `M5`, `M9`, `M30` |

## Steps

1. Load it in CNC12: no errors, and the preview inside the scrap.
2. The common procedure's Levels 1 and 3. Re-zero Z at each change as you normally do.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| CNC12 stops at both tool changes | Yes | | |

## Failure and what to report

The CNC12 version and board (Acorn, Oak, EX), how tool lengths are set, the error and line, and the measurements.
