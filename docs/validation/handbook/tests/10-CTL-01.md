## What to check at Level 0

| Line or block | Expect |
|---|---|
| Safety line | `G00 G94 G20 G17 G90 G40 G49 G80` (`G21` in the mm file), then `G91.1` and `G64` |
| Each tool change | `G00` up to safe Z and `M05` (from the second change on), a `(Change to Tool: …)` comment, `T1M6` (or `T2M6`), `M07`, `S18000 M03` (`S16000` for the third) |
| After the second and third `T#M6` | `G90 G91.1 G64` again before the next move |
| Dwell | `G04 P3.00`: a decimal point, which Mach4 reads as seconds |
| Arcs | `G02`/`G03` with `I`/`J`, each under 180° |
| End | Retract, park at `X0 Y0` at the park height, `M05`, `M09`, `M30` |
| M00 file (`-pause`) | `M00` with a message comment at each change, in place of `T#M6` |
| Line endings | CRLF (open in an editor that shows them, or trust Mach4 loading it) |

## Steps

1. Do the common procedure's Levels 0, 1 and 3 with `acceptance-avid.tap`.
2. At each `T#M6`, Avid's M6 macro should stop, ask for the bit, and run the touch plate. **Note whether it raises Z before moving** to the tool-change position.
3. Check Mach4 shows the `(MSG,…)` text, if any, and that the dwell runs 3 s.
4. Repeat Level 1 with `acceptance-avid-pause.tap` if you'd use the M00 mode (a setup without an M6 macro): the program must stop at each `M00` and resume on Cycle Start with the spindle restarted.
5. If you run Mach4 in millimetres, cut `acceptance-avid-mm.tap` instead and measure the same.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| M6 macro stops and touches off at both changes | Yes | | |
| M6 macro raises Z before moving (note yes or no) | — | | |
| `-pause` file stops at each `M00` and restarts the spindle | Yes | | |

## Failure and what to report

The file, Mach4's version and profile, the line the machine stopped at, a photo of the scrap with the calipers, and your table of measurements.
