## Setup

Two mortises, each 2 × 1 in and 0.375 in deep, at the top: the left with dogbones, the right with T-bones along X. A 2 × 1 in tenon is cut out through below them, on 4 tabs, with square outside corners.

## Steps

1. Level 0 and Level 1: watch the bit reach into each corner (along the diagonal for dogbones, along X for T-bones).
2. Level 3. Free the tenon, sand the tab stubs flush, and try it in each mortise both ways round.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Mortise length × width (between the walls, not the reliefs) | 2.000 × 1.000 in | ±0.005 in | | |
| Mortise depth | 0.375 in | ±0.005 in | | |
| Tenon length × width | 2.000 × 1.000 in | ±0.005 in | | |
| Dogbone notch: in each corner, along the diagonal | 4 notches | — | | |
| T-bone notch: in each corner, along X | 4 notches | — | | |
| Tenon goes fully into both mortises, corners not binding | Yes | — | | |

A tenon and mortise of exactly the same size make a tight fit by design; with both on the high or low side of their tolerance it may need a tap. What matters is that the corners don't stop it.

## Failure and what to report

A relief missing at a corner, cut on the wrong side, or cutting into the wall beyond the corner. Photos of each corner.
