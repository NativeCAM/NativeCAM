## Setup

The board is longer than one tile, not than your machine: the project sets an **8 in tile length** so any machine can try tiling. A 5 × 18 in panel with a slot, a star and two holes is cut out on tabs. The setup sheet has a page per tile: the file to run, how far to move the board and which way, and where the dowels go.

## Steps

1. Level 0: three files, `til-feed-through - tile 1 of 3.tap` and so on. Each drills the registration holes first.
2. Level 1 on tile 1: the two spoilboard holes in front of the board, then the two through the board 8 in further on.
3. Level 3. Set the XY zero once, at tile 1's corner (the setup sheet says where), and keep it. Run tile 1. Slide the board 8 in along Y, drop a dowel through each hole tile 1 drilled into the spoilboard hole under it, clamp, and run tile 2. Repeat for tile 3.
4. Check the seams: the slot and the panel's outline cross tile lines.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Dowels drop through the board's holes into the spoilboard holes after each move | Yes | — | | |
| Step across a tile line in the slot's walls and floor | 0.005 in or less | — | | |
| Step in the panel's outline at a tile line | 0.005 in or less | — | | |
| Panel overall length | 18.000 in | ±0.010 in | | |
| Re-entry at the breaks: a plunge or ramp mark only, no gouge | Yes | — | | |

## Failure and what to report

Holes that don't line up (measure how far off), steps at the seams (measure them), a tile cut in the wrong place. The setup sheet and photos of each seam.
