## Steps

1. Make the files. `post` must exit 0 and print no `[error]`. Read every `[warning]`.
2. Open `prf-coupon.tap` in a text editor and check the header against the setup sheet (`prf-coupon.html`, open it in a browser).
3. Load the file in your controller or sender, without running it. Compare its extents and preview with the header's `Program extents` line.
4. Simulate the project in NativeCAM (**⌘R**) or with `sim`, and compare with the picture below.
5. Repeat with the `-mm` file if your controller runs in millimetres.

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| `post` exit status | 0, no `[error]` lines | | |
| Units line | `G20` (inch file) / `G21` (mm file) | | |
| Header extents (inch) | X 1.175 to 8.450, Y 0.910 to 6.315, Z −0.770 to 0.100 in (the park move reaches X0 Y0 and Z 1 in) | | |
| Controller's extents | Match the header's | | |
| Tools listed | T1 1/4" Upcut End Mill only | | |
| Controller loads it without errors | Yes | | |
| Simulation | An on-line groove ring, a round hole and a square with 4 tabs, as pictured | | |
| Setup sheet | Material 10 × 8 × 0.75 in MDF, lower-left and top zero, three toolpaths, 4 tabs of 0.375 × 0.125 in | | |

## Failure and what to report

The file, `post`'s output, the controller's error message or a screenshot of its preview next to NativeCAM's.
