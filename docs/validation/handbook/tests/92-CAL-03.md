## Steps

1. Run the fit without `--apply` first. Read each value before and after, each section's error before and after, and the F-change (and, with the rotary times file, `G93`) verdicts.
2. If the values look sensible, apply them **to a copy** (`-o`), and check the run-time estimate of a kit project against a real run (VH-BAS-03) with the calibrated machine.
3. Never fill in times you didn't measure: the fit marks each value *measured* in the machine settings.

## Failure and what to report

The times file and the fit's full output. Whether the fitted values should become NativeCAM's shipped defaults for your machine is for the developers to decide from reports like yours.
