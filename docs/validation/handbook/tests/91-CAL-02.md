## Setup

For your own bit and material: `calibrate ladder my-machine.nativecam --tool 1 --material hardwood`. The recording sheet lists each rung's feed, RPM and chip per tooth, and where it sits against the chart (below, inside, above).

## Steps

1. Level 0 and Level 1.
2. Level 3. Cut the rungs in order, watching and listening. Stop if a rung sounds overloaded.
3. For each rung, look at the chips (dust, curls, chips) and the wall (burn marks, fuzz, chatter).

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Best rung (number, feed, RPM) | — | | |
| Rungs that burned (list) | — | | |
| Rungs that chattered or overloaded (list) | — | | |
| Does the best rung fall inside the chart's range? | — | | |

## Failure and what to report

Your best rung against the chart's range, with the material and bit, helps tune the chart: report it either way.
