## Setup

Two test fixtures from the repository: a turned table leg in a 3.75 in wrapped blank, with six flutes following the leg, cut with a 1/4 in ball let out 1 in. In one the flutes run **before** the leg's 3D rotary finish, through 25–35 mm of uncut stock; in the other, **after** it.

This is a read-only check of a safety refusal: there's nothing to cut. If you want to cut fluted legs, use the *after* project as a starting point only after VH-ROT-01, VH-ROT-02 and VH-ROT-07 pass, with your own blank and bits.

The *after* fixture's warnings (the turn speed isn't set, and its fixture's centre height may exceed the Z travel) come from the test fixture's machine, not from the flutes, and are expected.

## Steps

1. Post the *before* fixture (the second command). `post` must print the stickout error that the flutes go down "through the stock over the 3D model", write no file, and exit 1.
2. Post the *after* fixture (the first command). It must exit 0 with no error and no cutting-length warning.

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| *Before*: `[error]` about the stock over the 3D model, exit 1, no file | Yes | | |
| *After*: exit 0, no stickout error or cutting-length warning | Yes | | |

## Failure and what to report

A *before* file that's written is a safety finding (the collet nut would hit the stock): report it with `post`'s output and your build.
