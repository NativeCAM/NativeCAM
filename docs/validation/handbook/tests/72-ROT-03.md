## Setup

Measure your rotary's **centre height** above the spoilboard and set it under **Material & Machine ▸ Rotary Axis** before posting (the info line asks for it): it lets NativeCAM check the job fits under the Z travel. Zero X at the bar's left (chuck) end, Y on the axis, and Z **on the axis** (Avid: Rotary tab ▸ Z Axis Touch). Safe Z is 1.614 in from the axis, clear of the corners' 1.414 in swing.

## Steps

1. Level 0: four toolpaths, `Mortise @ 0°` to `@ 270°`, each preceded by `G00 A…` with Z at safe height. Note whether your M6 macro in rotary mode zeroes Z on the axis or on the face, and set your zero to match the setup sheet.
2. Level 1: the blank turns only with the tool at safe Z, and each mortise is on the face on top.
3. Level 3. Measure each mortise.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Four mortises, one on each face | Yes | — | | |
| Each mortise, length × width | 2.500 × 0.500 in | ±0.005 in | | |
| Each mortise centred on its face (across the face) | 1.000 in from each edge | ±0.010 in | | |
| Each mortise centred along the bar | X 6.000 in from the chuck end of the blank | ±0.010 in | | |
| Depth from the face | 0.250 in | ±0.005 in | | |
| A turns only with the tool at safe Z | Yes | — | | |

## Failure and what to report

A mortise off-centre across the face means Y zero isn't on the axis; depths that differ face to face mean the axis isn't level or Z zero isn't on the axis. Measurements per face.
