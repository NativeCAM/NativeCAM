commands:
- nativecam-cli surface --area 12x12 --one-way --stepover 90 --depth 0.01 -o surface-tram-12x12.tap
---
## Steps

1. Level 0. Read the header: `Z ZERO: TOP OF THE SPOILBOARD`, and the XY zero at the area's front-left corner. Read the warning that 90% stepover can leave ridges (intended here).
2. Level 1 with the air cut, `surface-tram-12x12 (air cut).tap`.
3. Level 3. Zero Z on the board with the touch plate on it, and run it.
4. Read the pattern: a spindle out of tram leaves a ridge (or a step) between lines, on one side of each line. Compare with your machine maker's tramming guide; adjust and repeat.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Area surfaced | 12 × 12 in | ±0.020 in | | |
| Every line cut climb, with a lift between lines | Yes | — | | |
| Ridge height between lines (feeler gauge or depth gauge) | Your maker's tram tolerance | — | | |
| Depth below the old surface | 0.010 in | ±0.003 in | | |

## Failure and what to report

The program, and photos of the ridges under raking light if the pattern doesn't make sense.
