## What to check at Level 0

| Line or block | Expect |
|---|---|
| Start | `G90 G94 G17`, `G20`, `G91.1`, `G64 P0.0004` (the arc tolerance) |
| Each tool change | `M5`, `T1 M6` then `G43 H1` (LinuxCNC's `M6` doesn't apply the length), `G90 G94`, `G64 P…`, `M8`, `S… M3` |
| Dwell | `G4 P3.00` |
| End | `M5`, `M9`, `M30` |

## Steps

1. Open it in LinuxCNC (or its simulator configuration first): it rejects anything it doesn't know, so a clean load is itself a check.
2. The common procedure's Levels 1 and 3. Check your tool table holds T1 and T2 with the lengths your touch-off sets, since `G43 H#` applies them.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Opens in LinuxCNC without errors | Yes | | |
| Depth after each `G43 H#` change | 0.50 mm ±0.13 | | |

## Failure and what to report

LinuxCNC's version and configuration (or PathPilot), how tool lengths are set, the error and line, and the measurements.
