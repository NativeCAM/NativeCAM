## Steps

1. Run `pkt-island.tap` in MDF. Partway through the pocket, press **E-stop**. Write down the line number your controller highlights, and look where the tool really is: note how many lines the highlight is ahead of the tool (or behind).
2. Make the restart file with that line (the second command). It snaps back to the start of that line's pass. Read its header and compare the line text it quotes with your controller's screen.
3. Re-home the machine. Check the G54 work offset against the setup sheet (X and Y zero at the lower-left corner): re-zero XY if it moved. Re-zero Z with the touch plate.
4. Jog Z clear and run the restart. At the stop over the restart point, check the tool is over the cut.
5. When the job is done, measure the floor where the restart joined.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Line text in the header matches the controller's screen | Yes | — | | |
| Highlighted line against the tool's real place (note lines ahead or behind) | — | — | | |
| G54 after the E-stop and re-home (note any change) | Unchanged | ±0.002 in | | |
| Step in the floor where the restart joined | 0.002 in or less | — | | |
| Witness mark in the wall at the restart (describe) | Faint or none | — | | |

## Failure and what to report

A step bigger than 0.005 in, or a restart that cut in the wrong place. Both files, the line number, and photos.
