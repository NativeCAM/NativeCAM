## Setup

Two rows of four 1/4 in holes, 1 in apart: the top row at Y 2.9 in is plunged 0.5 in deep; the bottom row at Y 1.1 in is pecked through in 0.125 in pecks with a full retract between pecks. X positions 1.5, 2.5, 3.5 and 4.5 in.

## Steps

1. Level 0. In the file: the pecks (`G01` down, `G00` up to the retract height, down again), and the dwell after each bottom (`G04 P0.50` on Mach4; the dwell's unit is the controller's own, so read it on yours).
2. Level 1. Count the pecks (7 per hole for 0.77 in) and time a dwell.
3. Level 3. Measure positions with calipers from the lower-left corner of the MDF, and depths with the depth rod.

## Pass criteria

| Hole centres, Y | 2.900 and 1.100 in | ±0.005 in | | |
| Plunged hole depth | 0.500 in | ±0.005 in | | |
| Pecked holes go through | Yes | — | | |
| Dwell at each peck hole's bottom | 0.5 s | ±0.2 s | | |

## Failure and what to report

A dwell that's 500 s or 0.5 ms means the dwell unit is wrong for your controller: stop and report it with the file. Holes out of position, or depths wrong.
