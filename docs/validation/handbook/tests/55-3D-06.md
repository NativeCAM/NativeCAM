## Setup

The model is a 256-sided disc of radius 60 mm, so its corners are 120 mm across. It comes with PR #205 (`Tests/CAMCoreTests/Fixtures/model-outline/`). Import it, add an outside profile on the model with the 1/4 in end mill, through, with tabs, and post.

## Steps

1. Level 0: post the job. Note the outline the app draws round the model: it now follows the facets.
2. Level 1, then Level 3 in scrap.
3. Measure the disc across opposite corners in at least four directions.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Diameter across the corners | 120.00 mm | +0.13 / −0 mm (never smaller, less bit deflection) | | |
| Facets visible as flats, evenly spaced | Yes | — | | |

## Failure and what to report

A disc smaller than 120 mm across the corners by more than the bit's deflection means the profile cut inside the model's outline (a gouge): report it with the file and measurements.
