## Steps

1. Level 0: the file loads T10 first, then `T2M6`. Read the setup sheet for the pocket's outline.
2. Level 1: watch the 1/2 in bit clear the open area, the stop at `T2M6`, then the 1/8 in bit cut only the corners, narrow parts and the walls.
3. Level 3. A 1/2 in bit at 10,000 RPM needs a spindle with power at that speed: if yours can't, skip Level 3 and say so.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Floor depth everywhere | 0.250 in (6.35 mm) | ±0.005 in | | |
| No visible step between the two bits' areas on the floor | Yes | — | | |
| Boss diameter | 0.750 in (19.05 mm) | ±0.005 in | | |
| Corners cleaned to the 1/8 in bit's radius | 1/16 in or less | — | | |

## Failure and what to report

A step in the floor at the boundary between the bits (a Z re-zero error or a wrong tool length), uncut areas, or the 1/8 in bit re-cutting the whole pocket.
