## Steps

1. Level 0. A V-carve is a single pass, so this restart is **exact**, at line 100 of the full file, a move in the middle of the letter with A turning (check line 100 of your `rot-wrapped.tap` is a `G01 … A…` move; if your build's file differs, pick another such line). The header gives the A reading over the restart point. The first wrapped move after the restart is `G93` with its own F.
2. Level 1: run the restart air cut from the A position the full file would have reached (turn A there first, as the header says). Watch A continue from there without turning back through whole turns.

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| A continues from the header's reading, no unwinding | Yes | | |
| First `G93` move at a sensible speed | Yes | | |
| `G94` before the program end | Yes | | |

## Failure and what to report

A unwinding, a lurch at the first `G93` move, or the end left in `G93`. Both files.
