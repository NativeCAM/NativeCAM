## Steps

1. Make the files and open `pkt-island.html` in a browser. Print it if you like: it's meant to print on one or two pages.
2. Check every line of the sheet against the project: material 8 × 6 × 0.75 in MDF, zero lower left and top, tools T1 then T2, the tool change between toolpaths 2 and 3 with its re-zero instruction.
3. Run the air cut and time it from Cycle Start to the end, **leaving out** the time you spend at the tool change. Note the estimate's cutting and rapid parts from `post`'s output.
4. Compare your time with the estimate less its tool-change allowance (`tool changes/pauses` in the estimate line, 60 s per change on a manual machine).

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Setup sheet: material, zero, tools and run order correct | Yes | | |
| Tool change listed between "Slot 1/4 in" and the rest pass, with T2 | Yes | | |
| Measured air-cut time (without the change) | Estimate's cutting + rapids ±15% | | |

Estimates use class-default accelerations until you run the timing suite (VH-CAL-01), so a larger difference is a finding, not a failure: report it with your machine's settings.

## Failure and what to report

The setup sheet (HTML or a PDF of it), `post`'s estimate line, your measured time, and your controller's acceleration settings.
