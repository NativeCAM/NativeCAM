## Setup

The corner-relief coupon (VH-CRN-01) with its toolpaths in two groups: **Mortises** (both mortises) and **Tenon** (the cut-out).

## Steps

1. Level 0: each file starts by loading T1, as a full file does. The Tenon files warn that they assume the two mortises were already cut, so their links stay low over that material: expected, since you run the Mortises file first. Over a fresh board, use the Retract Fully file.
2. Run `grp-mortises.tap` (Level 1, then Level 3).
3. Run `grp-tenon.tap` next, **without changing the bit**: its first `T1M6` asks for the bit already in the spindle. Note how your tool-change macro handles that (Avid: does the M6 macro cope?).
4. Air-cut `grp-tenon-retract-air (air cut).tap` over a fresh board: with Retract Fully, no move goes below the top between cuts.

## Failure and what to report

A link into uncut material, or a tool-change macro that fails when the tool is already loaded. Your controller and macro.
