## Setup

The relief of VH-3D-01, roughed adaptively, finished with the 1/4 in ball, then rest-finished with a 1/8 in ball at 135°, then cut out.

## Steps

1. Level 0: four toolpaths and three tool changes. The rest finish's moves should sit only in the relief's crevices.
2. Level 1, about 1 in above the material: check the helix entries, the step-up passes, and how your controller runs the many short moves and loops.
3. Level 3. Time each toolpath (the setup sheet lists the estimates).

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Rest finish cuts only in crevices the 1/4 in ball left | Yes | — | | |
| Crevices visibly sharper than in VH-3D-01 | Yes | — | | |
| No plunge marks where the rest pass enters its areas | Yes | — | | |
| Adaptive roughing runs without stutter | Yes | — | | |

| Tabs intact | Yes | — | | |

## Failure and what to report

The 1/8 in ball cutting the whole surface again, plunge marks, or the roughing loops slowing far below the estimate. Times per toolpath.
