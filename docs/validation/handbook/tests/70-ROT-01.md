## Steps

1. **Jog first.** With nothing in the way and the tool raised, mark the top of the blank with a pencil line. Jog A in the positive direction by 90°.
   - Axis along X (chuck at X−): the mark should roll **toward −Y** (toward the front, on most machines).
   - Axis along Y: the mark should roll **toward +X**.
2. If it rolls the other way, turn on **Reversed** under **Material & Machine ▸ Rotary Axis** for your machine, and post again. Write the result on the sign-off sheet.
3. **Air cut the letter.** Zero X at the blank's left end, Y on the axis and Z on the axis, then run `rot-wrapped-air.tap`. Watch the tool trace the letter F about 1 in above the dowel, and compare it with NativeCAM's simulation of the project (**⌘R**, which shows the blank turning): the tool and the blank must move the same way as in the simulation, and the F must come out the right way round when you read it from above, as in the simulation, not mirrored.
4. Optional: with a pen in a spring-loaded holder in place of the bit, and Z zeroed so the pen just touches, draw the F on the dowel (post the project without `--air-cut` for that). Read it from above: it must match the simulation, not its mirror image.

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| +A jog: which way the top rolled | −Y (along X) / +X (along Y) | | |
| Reversed setting needed? (note yes or no) | — | | |
| The F reads the right way round, not mirrored | Yes | | |
| The direction note in `post`'s output read and acted on | Yes | | |

## Failure and what to report

A mirrored F after setting the direction, or a controller that turns A the opposite way to its jog. Your rotary's make, how it's mounted (along X or Y, chuck at which end), and the controller's A settings.
