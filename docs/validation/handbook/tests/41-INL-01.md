## Setup

The design is an L with a small round hole in it. The **pocket** file cuts the main board; the **plug** file cuts the second board, mirrored left to right, standing proud by the pocket depth less the glue gap. Each setup sheet says which side it is.

## Steps

1. Level 0. Check each setup sheet's inlay block: side, P, G and C. Both use T5, the same V-bit.
2. Level 1 on each.
3. Level 3: cut the pocket board, then the plug board.
4. **Dry fit** before any glue: turn the plug face down over the pocket and press it in by hand. It should stop with its walls touching the pocket's walls, and a gap of about 0.020 in (0.5 mm) between the plug's top and the pocket's floor.
5. Measure the gap at the plug board's surface with feeler gauges, then glue, clamp, and cut or plane the plug board off.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Pocket flat depth | 0.200 in (5.08 mm) | ±0.005 in | | |
| Plug: walls touch the pocket's walls all round (dry fit) | Yes | — | | |
| Plug board stands off the pocket board (dry fit) | about 1/16 in (1.6 mm) surface clearance | — | | |
| Plug doesn't bottom out on the pocket floor | Yes | — | | |
| Plug's mirror image matches the pocket (the L faces the right way) | Yes | — | | |
| After glue-up and flushing: glue line thin and even, no gaps at corners | Yes | — | | |

## Failure and what to report

A plug that bottoms out (pocket floor ridges or a flat-tipped bit holding it up), won't go in, or goes in mirrored the wrong way. The bit's real angle and tip, the measured gap, and photos.
