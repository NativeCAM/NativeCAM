## Setup

For your own machine, pass your project: `nativecam-cli surface my-machine.nativecam -o surface-bed.tap`. The whole bed is your travel less 1/4 in (6 mm) at each side. The XY zero is the area's front-left corner, that inset in from the front-left limits of travel: NativeCAM doesn't know where your machine homes, so you set it.

## Steps

1. Level 0: read the header's zero instructions.
2. Home the machine. Jog to the front-left limits, back off 1/4 in in X and Y, and zero X and Y there. Zero Z on the spoilboard.
3. Level 1: run `surface-bed-air.tap` (Z raised 1 in). Watch both far corners: the program must not hit a soft limit.
4. Note where your machine homes (which corner) and its soft limits.

## Pass criteria

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Air cut completes without a soft-limit stop | Yes | | |
| Far corners reach within about 1/4 in of the limits | Yes | | |
| Where the machine homes (note the corner) | — | | |

Only once the air cut passes, and the bed is clear of every clamp and screw head, run `surface-bed.tap` if you want a fresh spoilboard.

## Failure and what to report

A soft-limit stop (which axis and where), with your machine's travel and the program's header.
