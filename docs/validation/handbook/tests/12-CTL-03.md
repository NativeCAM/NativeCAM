## What to check at Level 0

As for Grbl 1.1 (VH-CTL-02): three files, one per tool, `G90 G94 G17` and `G20`, `M8`, `S18000 M3`, `G4 P3.00` in file 2, no `G64` or `G43`, and `M5 M9 M30` at the end. Check your grblHAL's `$341` tool-change mode: if it's set to stop on `M6`, say so in your report, since NativeCAM could then write one file.

## Steps

1. Check mode (`$C`) on each file.
2. The common procedure's Levels 1 and 3, the three files in order, re-zeroing Z between them.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| `$C` on each file | No errors | | |
| `$341` setting (note it) | — | | |

## Failure and what to report

grblHAL's build and board (`$I`), the sender, the error or alarm and line, and the measurements.
