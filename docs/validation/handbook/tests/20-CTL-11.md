## What to check at Level 0

| Line or block | Expect |
|---|---|
| Files | Three `.nc` files, one per tool |
| Start | `G90`, `G21` (always mm), `M8`, `S18000 M3` |
| Comments | None at all |
| Arcs | None: circles are short `G1` lines |
| Dwell | `G4 P3.00` in file 2 |
| End | `M5`, `M9`, `M30` |

## Steps

1. Copy the files to the DSP's USB stick and open each one on the handheld: no errors. Check the DSP is set to millimetres.
2. The common procedure's Levels 1 and 3, the files in order, re-zeroing Z between them.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Each file opens on the DSP | Yes | | |
| Circles round, with no visible facets at the 50 mm radius | Yes | | |

## Failure and what to report

The DSP model and firmware, the message shown, and the measurements.
