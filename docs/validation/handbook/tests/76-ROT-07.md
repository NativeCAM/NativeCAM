## Setup

The app's **Demo Table Leg**. As for VH-ROT-06: set the turn speed and centre height, zero on the axis.

## Steps

1. Level 0, reading the turn-speed and chip-load warnings.
2. Level 1: the roughing's layers step down from the bar's corners; the finish follows the leg's profile.
3. Level 3.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Leg's profile matches the simulation | Yes | — | | |
| Roughing leaves an even skin for the finish (no bare spots, no thick steps) | Yes | — | | |
| Finished surface: no gouges, shoulders crisp | Yes | — | | |
| Diameters at three points along the leg against the simulation | Match | ±0.010 in | | |
| Job time against the estimate | Estimate ±15% | — | | |

## Failure and what to report

Gouges into the leg, steps left by the roughing that the finish didn't clear, or burning near the axis. The file and photos.
