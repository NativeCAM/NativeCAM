## Steps

1. Level 0. Only the plug is enabled; its boundary is the whole board.
2. Level 1: the V-bit clears the board's whole top outside the design in raster lines.
3. Level 3. Check the flats with a straightedge and depth gauge.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| The board's whole top outside the design carved down evenly | Yes | — | | |
| Depth of the flat outside the design | Pocket depth − glue gap + surface clearance: 0.150 − 0.020 + 0.0625 = 0.1925 in (4.89 mm) below the top | ±0.010 in | | |
| Raster ridges between lines | under 0.004 in (0.1 mm) | — | | |
| Plug's L stands proud with crisp edges | Yes | — | | |

## Failure and what to report

Uncut islands of the old surface, a flat at the wrong depth, or the raster lines leaving deep ridges.
