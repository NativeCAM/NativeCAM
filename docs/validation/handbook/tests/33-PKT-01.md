## Setup

The pocket is 5 × 2.75 in (120 × 70 mm) with 0.25 in (6 mm) corner radii, centred on an island 1 in (25 mm) across; the slot is 5 × 0.375 in (120 × 10 mm) with square corners. Both are 0.25 in (6 mm) deep.

## Steps

1. Level 0. The file has `T1M6`, the pocket and the slot, then `T2M6` and the rest pass: check the rest pass only visits the slot's four corners.
2. Level 1. At `T2M6` the machine must stop for the swap and touch-off.
3. Level 2 in foam if you like, then Level 3 in MDF.

## Pass criteria

Inch file (mm file in brackets).

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Pocket length and width | 5.000 × 2.750 in (120 × 70 mm) | ±0.005 in | | |

| Pocket and slot floor depth | 0.250 in (6.00 mm) | ±0.005 in | | |
| Floor: flat, no ridges taller than 0.005 in between passes | Yes | — | | |
| Slot width | 0.375 in (10.00 mm) | ±0.005 in | | |
| Slot corner radius after the rest pass (radius gauge) | 1/16 in (1.6 mm) or less | — | | |
| No visible step where the 1/8 in bit met the 1/4 in bit's wall | Yes | — | | |
| Program stopped at `T2M6`, re-zeroed | Yes | — | | |

## Failure and what to report

A step between the two bits' walls, uneven floor depths after the tool change (a re-zero error), corners not cleaned, or the 1/8 in bit cutting the whole slot again (rest not working). Photos with a radius gauge, and depths.
