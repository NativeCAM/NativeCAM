## Setup

This project is a test fixture: its walls are deeper (29 mm) than the bits' 3/4 in flutes, so `post` warns the shank would rub below the flutes. Read those warnings. **Run Level 3 only with bits whose flutes are long enough** (set their real flute length and stickout in the tool library and post again: the warnings must go). Otherwise stop at Level 1.

## Steps

1. Level 0. Read the three cutting-length warnings.
2. Level 1: check the waterline loops run smoothly as arcs, and the steep-and-shallow pass switches between rows and loops at the 45° boundary.
3. Level 3, only with long-flute bits.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| Waterline loops run without stutter | Yes | — | | |
| Walls: even steps, no gouges at the loops' joins | Yes | — | | |
| Steep and shallow: no gap or double cut at the 45° boundary | Yes | — | | |
| Pencil: one clean pass along the groove's crease | Yes | — | | |

## Failure and what to report

Stutter on the arcs (note the controller and its arc settings), gouges at loop joins, or uncut bands at the steep/shallow boundary.
