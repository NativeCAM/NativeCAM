## Setup

`nst-parts.nativecam` holds four brackets, six coasters (3.5 in across) and a 7 × 7 in frame with a 5 × 5 in window, all off the sheet: `post` refuses it as it stands. `nst-parts-nested.nativecam` is the same job after `nest` (the first command): the layout repeats exactly with the same seed. The kit's copy was nested this way; nesting it yourself must give the same layout.

## Steps

1. Level 0. Run the `nest` command and read its summary: all 11 parts placed, on 3 sheets, `Coaster 1 in Frame`. Open `nst-layout.svg` in a browser.
2. Post the nested project: three files, `nst-parts - sheet 1 of 3.tap` and so on, and one setup sheet with a page per sheet. Each file starts by loading T1.
3. Level 1 on sheet 1 (the frame and its coaster): the coaster in the window is cut out before the window is cut.
4. Level 3, one sheet at a time: zero at each sheet's lower-left corner and top.
5. Measure the gap between neighbouring parts' edges (not their cuts) with calipers.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| `nest`: placed, sheets, parts in holes | 11 of 11, 3 sheets, Coaster 1 in Frame | — | | |
| Smallest gap between two parts' edges | 0.625 in (or more) | −0.010 in | | |
| Smallest gap from a part to the sheet's edge | 0.625 in (or more) | −0.010 in | | |
| Coaster in the window cut out first, and its slug doesn't catch the bit | Yes | — | | |
| Coaster diameter | 3.500 in | ±0.005 in | | |
| Frame outside and window | 7.000 and 5.000 in square | ±0.005 in | | |
| Every part's tabs intact | Yes | — | | |

## Failure and what to report

Parts closer than the spacing, a toolpath that didn't follow its moved part, the window freed before its coaster was cut. The layout SVG, the setup sheet and photos.
