## What to check at Level 0

As for Grbl 1.1 (VH-CTL-02), except that comments may run to 126 characters. Three files, one per tool; `G4 P3.00` in file 2; no `G64`, `G43` or `M7`. If your `config.yaml` has a tool changer, NativeCAM can write `M6` for it: say so in your report.

## Steps

1. Load each file in FluidNC's WebUI (or your sender) and check it parses without errors.
2. The common procedure's Levels 1 and 3, the files in order, re-zeroing Z between them.

## Pass criteria

The common procedure's table, plus:

| Check | Target | Measured | ✓ |
|---|---|---|---|
| Each file loads without errors | Yes | | |

## Failure and what to report

FluidNC's version, the board, the sender, the error and line, and the measurements.
