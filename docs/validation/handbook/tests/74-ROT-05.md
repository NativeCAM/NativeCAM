## Setup

Only after VH-ROT-01 (direction) and VH-ROT-02 (`G93`) pass. Set your centre height. Zero X at the dowel's left end, Y and Z on the axis. The design sheet is the dowel unrolled: its middle is the top of the dowel at A0.

## Steps

1. Level 0: `G93` before the wrapped moves, an F word on every `G93` move, no arcs in `G93`, and `G94` again before the end. Read the warning that a wrapped design is true to size only at the wrap diameter (2 in): the bottom of the V comes out narrower round the blank.
2. Level 1 (VH-ROT-01's air cut).
3. Level 3.

## Pass criteria

| Check | Target | Tolerance | Measured | ✓ |
|---|---|---|---|---|
| The F reads the right way round (not mirrored) | Yes | — | | |
| Letter height along the dowel | about 1.25 in (cap height) | ±0.020 in | | |
| Letter centred 3 in from the dowel's left end | 3.000 in | ±0.020 in | | |
| Feed steady while A turns (no lurching or very slow moves) | Yes | — | | |
| `G94` back on at the end; the program ends normally | Yes | — | | |

## Failure and what to report

A mirrored letter (direction), a letter squashed or stretched round the dowel (diameter or `G93`), or lurching moves. The file, the controller and photos.
