# Nesting, sheets and tiling

Nesting places parts on sheets for you, and a job too big for one sheet is cut on several. Tiling cuts a board longer than the machine reaches, moving it between files. Both make several files from one project: check that each file starts by loading its first tool, and that the setup sheet has a page for each sheet or tile.
